Contributors
============

ASOkai is built by a small team of researchers and engineers. The following
people are responsible for the ongoing development and maintenance of the
project:

- Arash Ayat -- Author
- Nathalie Gocht -- Contributor
- Aleksandra Khatova -- Contributor
- Kian Jalilian -- Contributor
- Alexander Schliep -- Owner

**Community contributions**

We welcome community contributions of any size, from documentation fixes to new
features and bug reports. If you would like to get involved:

- Review the :doc:`contributor guide <contributor-guide/index>` for the current
  extension interfaces and development workflow.
- Open an issue or pull request on the `ASOkai GitHub repository
  <https://github.com/Schlieplab/ASOkai>`_.

**Acknowledgements**

Thanks to everyone who has reported issues, suggested improvements, or tested
early releases. Your feedback helps shape the direction of ASOkai.
